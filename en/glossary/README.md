# Financial Glossary

[中文术语表](../../glossary/README.md) | [English Home](../README.md)

This glossary collects core terms from the Xiaoyinsi investing wiki for beginners. It is not a complete dataset and does not grant an open-data license.

## U.S. stocks and company analysis

| Term | Short explanation | Related Chinese article |
| --- | --- | --- |
| Pre-market / After-hours trading | Trading outside regular market hours, usually with lower liquidity and wider spreads. | [盘前盘后交易](../../content/stocks/premarket-afterhours.md) |
| Market order / Limit order | A market order prioritizes execution; a limit order controls price. | [市价单和限价单](../../content/stocks/market-order-limit-order.md) |
| Bid-ask spread | The difference between the best bid and best ask; a direct trading cost. | [买卖价差](../../content/stocks/bid-ask-spread.md) |
| ETF | A basket of assets traded like a stock. | [ETF](../../content/stocks/etf.md) |
| Market capitalization | Share price multiplied by total shares outstanding. | [市值](../../content/stocks/market-cap.md) |
| Earnings report | A company’s periodic disclosure of financial and operating results. | [财报](../../content/stocks/earnings-report.md) |
| 10-K | The annual report filed by U.S. public companies. | [10-K 年报](../../content/stocks/annual-report-10k.md) |
| EPS | Earnings per share, often affected by buybacks, dilution, and one-time items. | [EPS](../../content/stocks/eps.md) |
| P/E ratio | Price-to-earnings ratio; how much the market pays for each unit of earnings. | [PE](../../content/stocks/pe-ratio.md) |
| Free cash flow | Operating cash flow minus capital expenditure. | [自由现金流](../../content/stocks/free-cash-flow.md) |
| ROIC | Return on invested capital; a measure of capital efficiency. | [ROIC](../../content/stocks/roic.md) |
| WACC | Weighted average cost of capital, often used as a DCF discount rate. | [WACC](../../content/stocks/wacc.md) |
| Share dilution | Reduction in per-share ownership caused by new shares or equity compensation. | [股权稀释](../../content/stocks/share-dilution.md) |
| Backlog | Orders not yet recognized as revenue; not all backlog becomes real revenue. | [积压订单质量](../../content/stocks/backlog-cancellation-quality.md) |
| Inventory write-down | A loss recognized when inventory value exceeds recoverable value. | [存货跌价](../../content/stocks/inventory-write-down-analysis.md) |

## Options and derivatives

| Term | Short explanation | Related Chinese article |
| --- | --- | --- |
| Call / Put | A call is a right to buy; a put is a right to sell. | [Call 与 Put](../../content/options/calls-and-puts.md) |
| Strike price | The price at which the option can be exercised. | [行权价](../../content/options/strike-price.md) |
| Expiration date | The date when the option right expires. | [到期日](../../content/options/expiration-date.md) |
| Option premium | The price paid by the buyer and received by the seller. | [期权权利金](../../content/options/option-premium.md) |
| Moneyness | Whether an option is in-the-money, at-the-money, or out-of-the-money. | [Moneyness](../../content/options/moneyness.md) |
| Implied volatility | Volatility implied by option prices; not a directional forecast. | [隐含波动率](../../content/options/implied-volatility.md) |
| Delta | Approximate sensitivity of option price to stock price movement. | [Delta 和 Gamma](../../content/options/delta-gamma.md) |
| Gamma | Sensitivity of Delta; can rise sharply near expiration. | [Gamma 风险](../../content/options/gamma-risk.md) |
| Theta | Time decay of an option. | [Theta](../../content/options/theta.md) |
| Vega | Sensitivity to implied volatility changes. | [Vega](../../content/options/vega.md) |
| IV crush | Rapid implied-volatility drop after an event. | [IV Crush](../../content/options/iv-crush.md) |
| Assignment | The option seller is required to fulfill the contract. | [行权与指派](../../content/options/exercise-assignment.md) |
| Adjusted option | An option whose deliverable changed after a corporate action. | [调整期权交割物](../../content/options/adjusted-option-deliverable-valuation.md) |
| Zero-bid option | An option with no visible bid; not the same as zero risk. | [零买价期权退出](../../content/options/zero-bid-option-exit.md) |

## Crypto and on-chain risk

| Term | Short explanation | Related Chinese article |
| --- | --- | --- |
| Bitcoin | The first major decentralized crypto asset using proof-of-work consensus. | [比特币](../../content/crypto/bitcoin.md) |
| Ethereum | A public blockchain for smart contracts and decentralized applications. | [以太坊](../../content/crypto/ethereum.md) |
| Stablecoin | A token designed to track fiat or another asset, with reserve and redemption risk. | [稳定币](../../content/crypto/stablecoin.md) |
| Perpetual futures | A derivative with no fixed expiration, usually kept near spot by funding rates. | [永续合约](../../content/crypto/perpetual-futures.md) |
| Funding rate | Periodic payment between longs and shorts in perpetual futures. | [资金费率](../../content/crypto/funding-rate.md) |
| Liquidation | Forced closing of a leveraged position when margin is insufficient. | [爆仓和强平](../../content/crypto/liquidation.md) |
| Seed phrase | The recovery secret for a wallet; anyone with it can usually control the funds. | [助记词](../../content/crypto/seed-phrase.md) |
| Wallet approval | Permission granted to a contract to move tokens. | [钱包授权](../../content/crypto/wallet-approval.md) |
| Smart contract | On-chain code that can execute transactions and hold assets. | [智能合约](../../content/crypto/smart-contract.md) |
| DEX | A decentralized exchange using smart contracts and liquidity pools. | [DEX](../../content/crypto/dex.md) |
| Cross-chain bridge | Infrastructure for moving or representing assets across chains. | [跨链桥](../../content/crypto/cross-chain-bridge.md) |
| Delegatecall | A smart-contract call that executes external code in the caller’s storage context. | [Delegatecall 风险](../../content/crypto/delegatecall-storage-risk.md) |
| Timelock | A governance delay between approval and execution. | [治理 Timelock](../../content/crypto/governance-timelock-operation.md) |
| TWAP | Time-weighted average price; reduces instant manipulation but adds lag. | [TWAP 窗口选择](../../content/crypto/twap-window-selection.md) |
