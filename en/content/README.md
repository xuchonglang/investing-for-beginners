## Recommended translation order

For SEO and reader usefulness, translate in this order:

1. Core beginner topics: trading hours, order types, ETFs, financial statements, valuation, stablecoins, wallets, and options basics.
2. Risk-control topics: stop loss, position sizing, margin, assignment, liquidation, approvals, phishing, and bridge risk.
3. Advanced reference topics: accounting adjustments, option microstructure, smart-contract upgrade risk, and DeFi protocol details.
