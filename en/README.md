# Investing Guide

[中文首页](../README.md) | [English README](../README.en.md)

This directory is the English mirror of the investing guide repository.

The Chinese version remains the source of truth for now. English pages follow the same structure and, where possible, the same slugs, so every Chinese article can have a stable English counterpart in the same repository.

## Path convention

Chinese files stay where they are:

```text
content/stocks/pe-ratio.md
content/options/implied-volatility.md
content/crypto/stablecoin.md
guides/投资入门指南.md
glossary/README.md
```

English files use the same slug under `en/`:

```text
en/content/stocks/pe-ratio.md
en/content/options/implied-volatility.md
en/content/crypto/stablecoin.md
en/guides/investing-for-beginners.md
en/glossary/README.md
```

This keeps both languages in one repository without breaking existing Chinese links.

## Translation status

The English homepage, beginner guide, glossary, and content index are now available. The full article mirror can be translated in batches under `en/content/` using the same slugs as the Chinese source files.

See [i18n notes](../i18n/README.md) for the maintenance rules.
